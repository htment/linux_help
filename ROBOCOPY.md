
```
# Сохраняем оригинальную кодировку
$oldEncoding = [Console]::OutputEncoding
[Console]::OutputEncoding = [System.Text.Encoding]::GetEncoding(866)

# Выполняем robocopy

robocopy "f:\ФОТКИ\ТУРЦИЯ 2018" "\\192.168.31.119\upload_119\SORT_files\UNSORT\ТУРЦИЯ 2018" /E /DCOPY:T /COPY:DAT /R:3 /W:5 /MT:8 

# Возвращаем исходную кодировку
[Console]::OutputEncoding = $oldEncoding
```
Основные параметры:

``"f:\ФОТКИ\ТУРЦИЯ 2018"``

Источник: Папка, из которой копируются файлы

``"\\192.168.31.119\upload_119\SORT_files\UNSORT\ТУРЦИЯ 2018"``

Назначение: Сетевая папка, куда копируются файлы

Ключи (параметры):
``/E - Copy Subdirectories, including Empty ones``
Копирует все подкаталоги, включая пустые

``/DCOPY:T - Directory Copy Timestamps``
Копирует временные метки каталогов (дата создания/изменения)

``/COPY:DAT - Copy Data, Attributes and Timestamps``

D - Data (содержимое файлов)

A - Attributes (атрибуты файлов)

T - Timestamps (временные метки)

Не копирует: SECURITY (права доступа), OWNER (владельца), AUDIT (аудит)

/R:3 - Retries on failed copies: 3
Количество повторных попыток при ошибках копирования: 3 раза

/W:5 - Wait time between retries: 5 seconds
Время ожидания между повторными попытками: 5 секунд

/MT:8 - Multi-Threaded with 8 threads
Многопоточное копирование с использованием 8 потоков

Значительно ускоряет копирование множества мелких файлов

Полезные дополнительные параметры (которые можно добавить):
/LOG:file.txt - Log output to file
Запись лога в файл

/MIR - Mirror mode
Синхронизация (удаляет в назначении то, чего нет в источнике)

/MOV - Move files
Перемещает файлы (удаляет из источника после копирования)

/PURGE - Delete destination files not in source
Удаляет файлы в назначении, которых нет в источнике

/NP - No Progress
Не показывает процент выполнения для каждого файла

/TEE - Output to console and log
Вывод одновременно на консоль и в лог-файл

Коды возврата Robocopy:
0 - Файлы скопированы успешно

1 - Скопированы не все файлы

2 - Дополнительные файлы или каталоги в назначении

4 - Обнаружены несовпадающие файлы

8 - Произошли ошибки

Ваша команда оптимальна для массового копирования с сохранением всех атрибутов и использованием многопоточности для ускорения процесса.
